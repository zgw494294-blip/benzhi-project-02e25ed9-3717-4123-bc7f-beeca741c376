# 口述史开放治理台

`oral-history-release-desk` 是一套在口述史资料公开前使用的本地浏览器工作台。它把授权边界、转录片段、敏感标注、确定性校核、遮蔽处置、独立复核、最终批准和发布包封存串成一条可验证证据链，适合口述史整理员、隐私复核员与档案开放负责人协作使用。

系统不依赖外部服务或 Node 构建链。Go 服务直接提供原生 HTML、CSS、JavaScript 页面和同源 JSON HTTP API，案件数据保存在带 `schemaVersion` 的本地文件账本中。每次写入均要求 `expectedVersion` 与幂等键，候选快照经 `Sync` 后原子 `Rename`；启动时会校验账本序列、案件版本和已封存发布包摘要。

## 构建与运行

要求 Go 1.22 或更高版本。

```bash
go build ./cmd/server
go run ./cmd/server -addr=127.0.0.1:19081
```

默认监听地址是 `127.0.0.1:19081`，服务拒绝绑定非回环 IP。也可以设置 `PORT` 为合法端口号，服务会监听 `127.0.0.1:<PORT>`；显式 `-addr` 可覆盖该配置。默认账本目录为 `./data`，可通过 `-data` 指定其他目录。

启动后访问 `http://127.0.0.1:19081/`。页面中的唯一主流程为：创建开放案并登记授权边界 → 在草拟期修订边界或批量登记转录片段 → 冻结并校核 → 查看风险摘要与运行差异 → 批量闭合阻断项并生成预览 → 提交独立复核 → 必要时定向整改与重校核 → 复核批准 → 开放负责人批准并封存发布包 → 核查证据目录或下载规范化 JSON 副本。

## 测试与自检

运行全部测试：

```bash
go test ./...
```

运行有界自检：

```bash
go run ./cmd/server -addr=127.0.0.1:19081 -selfcheck
```

`-selfcheck` 会创建临时数据目录，启动真实回环 HTTP 监听，通过 JSON API 完成建案、片段登记、冻结、校核、阻断处置、预览、复核、最终批准和摘要重算，然后优雅关闭并自行退出。自检不会写入正式 `./data` 目录。

## 数据与并发约束

- 草拟案件冻结后才可执行全量校核；只有全部阻断项都具有完整决定时才能生成发布预览并提交复核。
- 草拟案件可通过当前 `expectedVersion` 原子修订标题、访谈日期、用途、授权范围和限制条款；无实际变化的修订不会产生空版本。批量片段登记会在写入前一次返回全部行级顺序、时间和内容错误。
- 复核退回必须提供理由代码、说明和受影响片段；退回后只能修改这些片段，并只对它们执行定向重校核。
- `GET /api/v1/cases/{caseID}/risk-summary` 提供按严重度、`ruleCode`、片段与变化状态筛选的稳定风险汇总；查询只读取已持久化校核结论，不改变案件版本。
- 阻断处置批次会在落盘前对同一片段的候选发布文本进行冲突预检，整批决定只增加一个案件版本。
- 所有写接口使用请求体中的 `expectedVersion` 防止覆盖；`idempotencyKey` 相同且操作相同时返回首次成功快照，相同键不能复用于其他操作。
- 发布包包含规范化发布文本、有效处置清单、复核快照、固定版本摘要及 `sha256:` 摘要。封存后案件不可再修改，`GET /api/v1/cases/{caseID}/package` 返回可筛选证据目录，`GET /api/v1/cases/{caseID}/package/download` 下载字节稳定的完整 JSON 副本，`GET /api/v1/cases/{caseID}/package/verify` 可重算摘要；任何摘要不一致都会禁止目录读取和下载。
- 若账本截断、字段损坏、序列不连续、案件版本异常或发布包摘要不一致，服务会拒绝静默启动。
